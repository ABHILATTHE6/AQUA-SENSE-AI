| Days 4–7 | Data acquisition | First real source, ingestion pipeline, quality checks |
| Days 8–11 | Data engineering | Storage model, transformations, reproducible datasets |
| Days 12–16 | Data science | EDA, temporal patterns, water-stress index, feature engineering |

| Days 33–35 | Productionization | Docker, CI, tests, monitoring, documentation |
